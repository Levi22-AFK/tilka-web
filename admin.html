¿Cómo creo el token?
  1. En GitHub abre Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y marca solo el repositorio de la página.
  3. En Permissions pulsa Add permissions, agrega Contents y cámbialo a Read and write.
  4. Pulsa Generate token, cópialo y pégalo arriba.

Restablecer acceso. Con un token de GitHub válido del repositorio puedes volver a crear tu cuenta de administrador.

Las demás cuentas dejarán de funcionar y tendrás que crearlas de nuevo desde Usuarios.

Mínimo 10 caracteres.

El token de GitHub del calendario venció o fue eliminado. Como administrador, pega un token nuevo; el resto del equipo podrá seguir entrando con sus mismas contraseñas.

Las contraseñas nunca se guardan ni se envían: solo sirven para descifrar, en tu navegador, el acceso a GitHub.

Cuentas del equipo

Ten en cuenta
  • Crea cuentas solo para personas de confianza: cualquier cuenta puede modificar el calendario.
  • Al crear una cuenta, comparte la contraseña en persona o por un mensaje privado, y pide que la cambien en «Mi contraseña».
  • Si eliminas a alguien que ya había entrado, pulsa también Actualizar token de GitHub con un token nuevo (y borra el anterior en GitHub) para cerrarle el acceso por completo.
