¿Cómo creo el token?
  1. En GitHub abre Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Ponle un nombre (por ejemplo «Calendario TILKA») y una fecha de vencimiento.
  3. En Repository access elige Only select repositories y marca solo el repositorio de la página.
  4. En Permissions → Repository permissions → Contents elige Read and write.
  5. Pulsa Generate token, cópialo y pégalo arriba. GitHub solo lo muestra una vez.

El token se guarda cifrado con tu contraseña y solo en este dispositivo. Nunca se envía a otro sitio que no sea GitHub.
